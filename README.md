# SQL-Online-Bookstore-Analysis


## About the Project

I made this project to practice SQL using an online bookstore database. The database has three tables: Books, Customers, and Orders.

## What I Did

I worked on different SQL questions and wrote queries to find answers from the data. I practiced basic as well as advanced SQL queries.

- Finding books by genre and publication year.
- Checking book prices and available stock.
- Calculating total revenue and quantity of books sold.
- Finding customers who placed multiple orders.

## SQL Topics Used

- Database and Table Creation (DDL)
- SELECT and WHERE
- JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
- COALESCE
- Subqueries

## Tools Used

- MySQL
- MySQL Workbench
- Excel

## Project Files

- `online_bookstore_questions.docx` – Contains the questions I worked on.
- `online_bookstore_queries_answers.sql` – Contains my SQL queries with answers.
- `online_bookstore_data.xlsx` – Contains the original data.

## What I Learned

While working on this project, I got more practice with SQL and learned how to connect tables and find useful information from data. I also improved my understanding of SQL queries by solving different questions.

I used a YouTube tutorial for guidance while making this project and practiced writing the queries on my own.
